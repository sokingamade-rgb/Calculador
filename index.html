📸🤖 Sabí IA — Resolver exercícios

Escreve um exercício de matemática, física ou química, ou tira uma fotografia. O motor de IA pode explicar a resolução passo a passo quando estiver ligado a um servidor.

Pronto para receber o exercício. Para analisar fotografias e perguntas livres, configura o motor de IA abaixo.
⚙️ Ligar motor de IA (servidor seguro)

Introduz o endereço HTTPS do teu próprio servidor de IA. Nunca coloques uma chave secreta neste HTML: a chave deve ficar guardada no servidor. O servidor deve aceitar POST JSON com {question, image} e devolver JSON com {answer}. O servidor precisa permitir pedidos desta aplicação (CORS).

ℹ️ Sem servidor, a fotografia só é mostrada no ecrã; não é analisada automaticamente. A análise por IA exige internet e um servidor configurado.
